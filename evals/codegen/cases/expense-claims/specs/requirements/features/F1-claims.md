# Claims

## Purpose

An employee submits expense claims and follows each one until it is decided.

## User Stories

- F1.1 As an Employee, I want to submit an expense claim with amount, date, category, and description, so that I can request reimbursement.
- F1.2 As an Employee, I want to view the status of my submitted claims (pending, approved, rejected), so that I know where each stands.
- F1.3 As an Employee, I want to edit or withdraw a claim while it is still pending, so that I can correct mistakes before it is reviewed. *assumed*
