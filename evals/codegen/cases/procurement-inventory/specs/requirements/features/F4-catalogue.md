# Catalogue

## Purpose
A warehouse clerk keeps the item catalogue that requests and stock are built on.

## User Stories
- F4.1 As a Warehouse Clerk, I want to add a catalogue item with its name, unit, unit price and reorder level, so that it can be requested and stocked.
- F4.2 As a Warehouse Clerk, I want to edit an item's name, unit, unit price and reorder level, so that the catalogue stays correct.

## Decisions
- Warehouse clerks manage the item catalogue in the app; a new item starts with 0 in stock.
