> **Rationale:** Build-order edge to procurement-api; gated on platform resource user-auth (thunder-app).

## Scope
Implement the React SPA per specs/design/components/procurement-webapp/design.json and its prototype (prototype.json, prototype.tsx), using the Oxygen UI design system, signing in via Thunder SSO (user-auth, platform-resource gate platform-authored). Calls only procurement-api (see its openapi.yaml); role-specific navigation per sidebar.

Screens: Catalogue (screen.catalogue), Raise a request (screen.new-request), My requests (screen.my-requests), Request detail (screen.request-detail), Approval queue (screen.approval-queue), Approval detail (screen.approval-detail), Orders to receive (screen.orders), Receive goods (screen.receive), Stock (screen.stock), Item ledger (screen.item-ledger), Manage catalogue (screen.catalogue-manage), Account (screen.account), Settings (screen.settings), Signed out (screen.signed-out)

Flows:

- [ ] **Flow 1 · Browse the catalogue** (`flow.browse-catalogue`)
  Persona: Requester
  Stories: F1.1
  Walk: Catalogue
- [ ] **Flow 2 · Raise a purchase request** (`flow.raise-request`)
  Persona: Requester
  Stories: F1.2
  Walk: Catalogue → Raise a request → My requests
- [ ] **Flow 3 · Follow my requests** (`flow.track-requests`)
  Persona: Requester
  Stories: F1.3
  Walk: My requests → Request detail
- [ ] **Flow 4 · Review pending requests** (`flow.review-queue`)
  Persona: Approver
  Stories: F2.1
  Walk: Approval queue
- [ ] **Flow 5 · Approve or reject a request** (`flow.decide-request`)
  Persona: Approver
  Stories: F2.2, F2.3
  Walk: Approval queue → Approval detail
- [ ] **Flow 6 · Receive goods against an order** (`flow.receive-goods`)
  Persona: Warehouse Clerk
  Stories: F3.1, F3.2
  Walk: Orders to receive → Receive goods
- [ ] **Flow 7 · View an item's ledger** (`flow.trace-ledger`)
  Persona: Warehouse Clerk
  Stories: F3.2, F3.3
  Walk: Stock → Item ledger
- [ ] **Flow 8 · View the low-stock view** (`flow.view-low-stock`)
  Persona: Warehouse Clerk
  Stories: F3.4
  Walk: Stock
- [ ] **Flow 9 · Add a catalogue item** (`flow.add-item`)
  Persona: Warehouse Clerk
  Stories: F4.1
  Walk: Manage catalogue
- [ ] **Flow 10 · Edit a catalogue item** (`flow.edit-item`)
  Persona: Warehouse Clerk
  Stories: F4.2
  Walk: Manage catalogue

No flow: none — every story is walked above (sign-in/out is owned by platform SSO; story F3.2, a ledger entry on every stock change, shows in the item's ledger).

## Acceptance
- Every screen and flow above is implemented and walkable in mock mode.
- Build and lint pass; role gating matches security.json.
