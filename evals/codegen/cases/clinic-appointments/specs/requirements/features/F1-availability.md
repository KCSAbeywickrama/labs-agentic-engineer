# Availability

## Purpose
A doctor publishes the time slots patients can book, and keeps them accurate.

## User Stories
- F1.1 As a doctor, I want to publish my availability as time slots, so that patients can book them.
- F1.2 As a doctor, I want to remove an unbooked slot, so that my availability stays accurate.

## Decisions
- Slot length is chosen by the doctor when publishing. *assumed*
