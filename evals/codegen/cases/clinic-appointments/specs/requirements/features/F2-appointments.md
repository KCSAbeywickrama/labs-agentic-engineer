# Appointments

## Purpose
A patient finds a free slot, books it, and reschedules or cancels their own appointments.

Needs: F1.

## User Stories
- F2.1 As a patient, I want to browse available slots by doctor and date, so that I can choose a time that suits me.
- F2.2 As a patient, I want to book an available slot, so that I have a confirmed appointment.
- F2.3 As a patient, I want to reschedule my appointment to another available slot, so that I can adapt to changes.
- F2.4 As a patient, I want to cancel my appointment, so that the slot is freed for others.
- F2.5 As a patient, I want to see my upcoming and past appointments, so that I know my schedule.
