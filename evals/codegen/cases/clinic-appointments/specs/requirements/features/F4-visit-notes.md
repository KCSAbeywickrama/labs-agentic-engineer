# Visit notes

## Purpose
A doctor sees their appointments for the day and records each visit in notes only doctors can read.

Needs: F2.

## User Stories
- F4.1 As a doctor, I want to see my appointments for the day, so that I can prepare for my visits.
- F4.2 As a doctor, I want to write visit notes on an appointment, so that the patient's care is recorded.
- F4.3 As a doctor, I want visit notes to be readable only by doctors, so that patient information stays confidential.

## Decisions
- Visit notes are readable and writable only by doctors; any doctor may read notes of their own appointments only. *assumed*
