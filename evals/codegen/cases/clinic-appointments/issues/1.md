Version `v1`: the spec is `specs/` at tag `v1`.

- [ ] **foundation** Shared setup and product-wide requirements: `clinic-api`, `clinic-webapp`. Set up both components for the first time: Ballerina service verifying the gateway's signed assertion with the user-auth wiring and security.json scopes (P4), and the React app with Oxygen UI shell, Thunder SSO, role-based nav, and CLINIC_API_URL wiring. Establish the shared clinic time zone handling (P5) and the transactional booking/cancellation rule helpers (P1, P2) the features reuse.
- [ ] **F1** Availability: `clinic-api`, `clinic-webapp`. Build /me, /doctors, /slots, /me/slots (single and batch) and DELETE /me/slots/{slotId}, then the My availability and Open slots screens. Enforce future-only, no-overlap, and no removal of booked slots.
- [ ] **F2** Appointment booking: `clinic-api`, `clinic-webapp`. Build the /me/appointments endpoints (book, reschedule, cancel) with P1 atomic booking, P2 cut-off, no overlapping appointments for a patient, and no booking of started slots. The web app's My appointments screen must show clear slot-taken and too-late messages.
- [ ] **F3** Reception and check-in: `clinic-api`, `clinic-webapp`. Build /patients search and register, /appointments list/book/reschedule/cancel, and check-in with undo (booked and same-day only), reusing F2's booking rules with no override. Web screens are Front desk and Patients, plus the book-for-patient dialog on Open slots.
- [ ] **F4** Doctor's day and visit notes: `clinic-api`, `clinic-webapp`. Build /me/consultations, visit-notes create/list/update, and /patients/{patientId}/visit-notes, restricted to doctors and the doctor's own appointments (P3, with 404 for others). Notes are allowed only when checked in or started, and cannot be deleted. Web screens are My day and the Consultation screen.

Product-wide: P1, P2, P3, P4, P5
