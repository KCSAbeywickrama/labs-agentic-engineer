# Ticket queue

## Purpose
Support agents and the team lead see the whole queue, filter it, and spot SLA breaches.

Needs: F1.

## User Stories
- F4.1 As a Support Agent, I want to view the queue filtered by status, priority, assignee and SLA breach, so that I can find what to work on.
- F4.2 As a Team Lead, I want to view the whole queue with SLA breaches highlighted, so that I can see where we are falling behind.

## Decisions
- An SLA breach is a ticket not resolved past its due time. *assumed*
