# Comments

## Purpose
Employees and support agents talk on a ticket through its comment thread.

Needs: F1.

## User Stories
- F2.1 As an Employee, I want to add comments to my ticket, so that I can give or receive more information.
- F2.2 As a Support Agent, I want to comment on a ticket, so that I can communicate with the requester and colleagues.

## Decisions
- Comments are visible to all participants including the requester; no internal-only notes. *assumed*
