# Ticket comments

## Purpose
Employees and support agents discuss a ticket in its comment thread.

Needs: F1.

## User Stories
- F3.1 As an employee, I add a comment to one of my tickets. *assumed*
- F3.2 As a support agent, I add a comment to any ticket. *assumed*
- F3.3 As a team lead, I add a comment to any ticket. *assumed*
- F3.4 As an employee, I read the comment thread on my ticket, oldest first, with each comment's author and time. *assumed*
- F3.5 As a support agent, I read the comment thread on any ticket. *assumed*

## Decisions
- Comments are plain text; no attachments or formatting. *assumed*
- Comments cannot be edited or deleted once posted. *assumed*
- Every comment is visible to everyone who can see the ticket; there are no internal-only notes. *assumed*
- Comments can be added on a ticket in any status, including resolved. *assumed*

## Out of Scope
- Notifying anyone of a new comment.
- File attachments in comments.
- Internal notes hidden from the employee.
