# Raising tickets

## Purpose
An employee raises a ticket and follows its status and SLA due time.

## User Stories
- F1.1 As an Employee, I want to raise a ticket with a title, description and priority, so that IT knows what I need.
- F1.2 As an Employee, I want to see the list and status of my own tickets, so that I know where my requests stand.
- F1.3 As an Employee, I want to see the SLA due time on my ticket, so that I know when to expect a response.
