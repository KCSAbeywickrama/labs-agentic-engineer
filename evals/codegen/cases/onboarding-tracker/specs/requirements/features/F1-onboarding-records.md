# Onboarding records

## Purpose

HR creates a new hire's onboarding record, shapes its task list, and closes it out once every task is done.

## User Stories

- F1.1 As an HR Coordinator, I want to create a new hire's onboarding record, so that IT, HR and Facilities all know a new onboarding has started.
- F1.2 As an HR Coordinator, I want the onboarding record to be pre-populated with a standard set of tasks for each department, so that I don't have to build the task list from scratch every time. Needs: F4. *assumed*
- F1.3 As an HR Coordinator, I want to add, edit or remove individual tasks on a specific new hire's onboarding record, so that I can handle exceptions to the standard checklist.
- F1.4 As an HR Coordinator, I want to set a due date on each task, so that overdue items can be identified.
- F1.5 As an HR Coordinator, I want to mark a new hire's onboarding as complete once every task across all departments is done, so that the record can be closed out.
