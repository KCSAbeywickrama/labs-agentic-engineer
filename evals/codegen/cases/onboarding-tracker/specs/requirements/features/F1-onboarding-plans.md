# Onboarding plans

## Purpose
HR coordinators start an onboarding for a new hire with their start date and the set of tasks across IT, HR and facilities.

## User Stories
- F1.1 As an HR coordinator, I start an onboarding for a new hire by entering their name, role and start date. *assumed*
- F1.2 As an HR coordinator, I see a list of all onboardings with each new hire's start date and progress. *assumed*
- F1.3 As an HR coordinator, I get a default set of IT, HR and facilities tasks when I start an onboarding. *assumed*
- F1.4 As an HR coordinator, I add, edit or remove tasks on a new hire's onboarding. *assumed*
- F1.5 As an HR coordinator, I give each task a department, a due date and a text description. *assumed*
- F1.6 As an HR coordinator, I assign each task to a department team, so its team members see it. *assumed*
- F1.7 As an HR coordinator, I close or cancel an onboarding. *assumed*

## Decisions
- The default task set is one template shared by all new hires; due dates default to offsets from the start date. *assumed*
- Tasks hold text only; no attachments. [org default]
- Task owners are departments (IT, HR, Facilities), not named individuals. *assumed*

## Out of Scope
- Multiple templates per role or location.
- Email or other notifications to new hires or owners.
