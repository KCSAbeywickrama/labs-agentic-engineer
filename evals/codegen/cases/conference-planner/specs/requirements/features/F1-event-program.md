# Event program

## Purpose
Organizers set up events with rooms and sessions; attendees browse what is on.

## User Stories
- F1.1 As an organizer, I want to create and edit events, so that I can set up a conference.
- F1.2 As an organizer, I want to define rooms for an event, so that sessions have a venue.
- F1.3 As an organizer, I want to create sessions with a room, time slot and capacity, so that the schedule is built.
- F1.4 As an attendee, I want to browse events and their sessions, so that I can decide what to attend.
