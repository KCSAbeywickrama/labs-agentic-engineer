# Multi-Environment Deployments — Implementation Plan 2: The Environment Page

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One page per environment at `/projects/$projectName/deployments/$environment`, in four sections — Deployment, Try it out, Dependencies, Past deployments — replacing both the try-out page and the per-version page.

**Architecture:** The existing `DeploymentTryOutPage` becomes this page, served from `$environment.index` instead of a redirect. It gains a deployment-summary section above the try-out panels and a history section below the dependencies table. `DeploymentVersionPage` and its route are deleted; a superseded version is a row, not a page. Past deployments is honest about a platform that records no history: real rows on the first environment, the current row plus a stated absence everywhere else.

**Tech Stack:** TypeScript/React 19, Oxygen UI, React Query, TanStack Router, vitest + @testing-library/react.

**Spec:** [`docs/design/multi-environment-deployments.md`](multi-environment-deployments.md) §4.3, §6 and §9. **Depends on plan 1** — `environments.ts`, `useEnvironments`, and the widened `EnvironmentDTO` must exist before Task 1.

## Global Constraints

Everything in [plan 1's Global Constraints](multi-environment-deployments-plan-1.md#global-constraints) applies unchanged. Additionally:

- **Past deployments must never invent a row.** Only the first environment has real history, from the build ledger. Every other environment shows what runs now and the sentence *No earlier deployments are recorded for this environment.*
- **Roll back ships disabled** with the tooltip `Not supported yet`, on every row. No exceptions, including the running row (which additionally has nothing to roll back to).
- The section order is fixed: Deployment, Try it out, Dependencies, Past deployments.
- Deletions happen in the task that replaces the thing, never speculatively ahead of it.

- Consumes: plan 1's `EnvironmentInfo`, `EnvironmentRow`; the existing `BuildSummary[]` from `useProjectBuilds`; `versionLedgerRows`' row-status vocabulary in `deploymentLedger.ts`.
- Produces:

```ts
export interface HistoryRow {
  version?: string;
  milestoneNumber?: number;
  validation?: string;
  deployedAt?: string;
  /** Absent on the running row, which is marked `current` instead. */
  until?: string;
  current: boolean;
}

export interface HistoryView {
  rows: HistoryRow[];
  /** True when the platform records nothing for this environment beyond now. */
  unrecorded: boolean;
}

export function historyFor(
  env: EnvironmentInfo,
  row: EnvironmentRow | undefined,
  builds: BuildSummary[] | undefined,
): HistoryView;
```

- [ ] **Step 1: Write the failing tests**

```ts
describe("historyFor", () => {
  const first = env({ name: "development", position: 0, validation: "on", promotesTo: "staging" });
  const later = env({ name: "staging", position: 1, promotesTo: "production" });

  it("gives the first environment the build ledger, newest first, marking the live version", () => {
    const view = historyFor(first, rowRunning("v3"), [b("v1"), b("v2"), b("v3")]);
    expect(view.unrecorded).toBe(false);
    expect(view.rows.map((r) => r.version)).toEqual(["v3", "v2", "v1"]);
    expect(view.rows[0]?.current).toBe(true);
    expect(view.rows[0]?.until).toBeUndefined();
  });

  it("closes each superseded row at the moment the next one deployed", () => {
    const view = historyFor(first, rowRunning("v3"), [b("v1"), b("v2"), b("v3")]);
    expect(view.rows[1]?.until).toBe(view.rows[0]?.deployedAt);
  });

  it("gives a later environment only what runs now, and says the rest is unrecorded", () => {
    const view = historyFor(later, rowRunning("v2"), [b("v1"), b("v2"), b("v3")]);
    expect(view.unrecorded).toBe(true);
    expect(view.rows).toHaveLength(1);
    expect(view.rows[0]).toMatchObject({ version: "v2", current: true });
  });

  it("gives an empty later environment no rows at all, rather than a blank one", () => {
    const view = historyFor(later, undefined, [b("v1")]);
    expect(view.rows).toEqual([]);
    expect(view.unrecorded).toBe(true);
  });

  it("never invents a later environment's past from the build ledger", () => {
    const view = historyFor(later, rowRunning("v2"), [b("v1"), b("v2"), b("v3")]);
    expect(view.rows.map((r) => r.version)).not.toContain("v1");
  });
});
```
