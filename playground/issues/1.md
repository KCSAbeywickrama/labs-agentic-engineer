> **Rationale:** Owns todo/list CRUD, completion toggling, and per-user data isolation, gated on the user-auth Thunder platform resource for identity headers.

## Scope

Implement the `todo-api` Go service per `specs/design/components/todo-api/design.json`:

- Todo CRUD: create, list (with status filter all/active/completed), get, update, delete — all scoped to `X-User-Id` from the gateway.
- List CRUD: create, list, rename, delete — scoped to `X-User-Id`.
- Dedicated complete/incomplete toggle action for a todo.
- Deleting a non-empty list must not silently delete its todos: either reassign them to the default (unlisted) list or require the caller to specify handling explicitly (see design.md Data flow #5 and REQ-006 AC-006-c).
- Data model: `Todo{id, userId, listId?, title, description?, dueDate?, done, createdAt, updatedAt}`, `List{id, userId, name, createdAt}`. `listId = null` means "unlisted".
- No `/auth/*` endpoints; do not validate JWTs — trust `X-User-Id` injected by the gateway, reject with 401 if missing.
- Persist to embedded SQLite (`modernc.org/sqlite`, driver name `sqlite`) at `/data/todo-api.db`.

## Acceptance criteria

- POST create todo rejects empty title with a validation error (REQ-002 AC-002-b); accepts optional description/dueDate; sets `done=false` initially.
- GET list todos supports a status filter query param returning only matching todos (REQ-003 AC-003-e).
- PATCH edit todo persists title/description/dueDate changes; rejects empty title (REQ-004 AC-004-a/b).
- PATCH complete/reopen toggles `done` (REQ-005 AC-005-a/b).
- DELETE todo removes it permanently (REQ-006 AC-006-a).
- DELETE list with todos either moves them to the default list or returns a response requiring the caller to specify handling — never silently deletes todos (REQ-006 AC-006-c).
- All endpoints scope reads/writes to `X-User-Id`; a request referencing another user's todo/list id returns a not-found/denied response, never another user's data (REQ-007 AC-007-a/b).
- Changes persist across requests/sessions (REQ-007 AC-007-c).
